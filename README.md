# SmartExamPlanner-Backend
## Title
An automated system designed to streamline the assignment of lecturers and exam halls for university examinations. 

## 📄 Overview
The system automates the scheduling of lecturers (as invigilators and supervisors) and allocation of exam halls, ensuring efficiency, fairness, and transparency. It replaces a manual process that is error-prone and time-consuming, particularly during exam seasons.

## ✅ Core Features (MVP)
- Input and manage exam timetables with subject, date, and student count.
- Input and manage lecturer details (name, rank, faculty, availability).
- Automatically assign supervisors and invigilators to sessions.
- Generate downloadable and printable reports of duty allocations.

## ✨ Extended Features
- Assign exam halls based on capacity and availability.
- Detect scheduling conflicts for staff and halls.
- Support multi-user access with role-based permissions.
- Dashboard for real-time assignment summary.
- Audit logs and manual override tracking.
- Notifications via email/SMS to assigned staff.
